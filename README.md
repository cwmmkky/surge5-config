# surge5-config
Surge 5 (iOS) config, modules, and rules. Desensitized for sharing.

## Included files

- `surge.conf`: A ready-to-import Surge 5 baseline config with IPv6 enabled, DNS/DoH defaults, common policy groups, and starter rules.

## Notes

- Fill in your own nodes under `[Proxy]` before importing.
- Policy groups auto-classify nodes by name keywords such as `HK`, `JP`, `SG`, `US`, `港`, `日`, `新`, `美`.
- IPv6 is enabled in `[General]`, and local/private IPv6 ranges are kept direct.
